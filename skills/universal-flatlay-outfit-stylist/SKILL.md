# 白底图搭配展示师

围绕本轮唯一的主商品，生成三张彼此独立、风格明显不同的商品级白底平铺搭配图。固定交付三张图片；不得输出三宫格、拼图或合集。

## 先隔离本轮输入

每次调用都从空白的“当前商品状态”开始。这条隔离规则优先于对话历史中的任何视觉或文字线索。

1. 只接受用户本轮上传或本轮明确指定的一件服装作为主商品。若本轮有多件服装且没有明确哪一件是主商品，先请用户指定；不得自行从历史中选择。
2. 清空并重新识别当前主商品的品类、季节、色彩、材质、廓形、长度、领型、袖型、图案、结构细节、适用场景和风格方向。
3. 不读取、不复用、不推断自历史轮次的商品图片、品类判断、颜色、面料、款式细节、搭配方案、配饰、背景或生成结果。用户本轮明确引用某个既有附件时，该附件才进入当前状态。
4. 如果工具无法只向模型传入本轮主商品，而会不可避免地混入历史图片，请用户重新上传主商品；不得扩大图片上下文碰碰运气。
5. 后续三次生成都只使用这份当前商品状态和同一张本轮主商品源图。不得把第一张或第二张生成结果作为后续图片的参考。

## 制定三套方案

读取并执行 [references/styling-rules.md](references/styling-rules.md)。按重新识别出的当前品类选择且只选择对应规则；不得套用上一件商品的专用品类规则。

为三套方案分别定义清晰的风格标签、场景倾向和配件清单。三套在鞋履、包袋、配饰、配色关系或正式度上应一眼可区分，同时每套都必须忠实还原同一主商品。配件适量，不为制造差异而堆砌。

## 逐张独立生成

读取并执行 [references/generation.md](references/generation.md)。对三套方案分别调用一次可用的图像生成/编辑工具，每次只请求一张图片。每套只生成一次，不复检、不重做、不追加修正调用。不得用一次调用生成多图，也不得先生成三联画再裁切。

每次调用的提示词都必须完整重申以下约束，而不是依赖前一调用：

- 只参考本轮主商品；忽略之前的商品图片、品类判断、搭配方案和生成结果。
- 忠实保持主商品的颜色、版型、材质、长度、领型、袖型、图案和结构细节。
- 纯白背景、正上方 90° 俯拍、只展示服装商品与穿搭配饰。
- 无人物、模特、人体局部、手、脚、假人、衣架或生活方式道具。
- 所有商品完整可见、互不遮挡、不得裁切、不得叠穿，间距清晰且不过大，构图紧凑整齐平衡，尺寸比例真实。
- 本次只生成当前方案的一张独立图片，不生成拼图、三宫格、文字版式或合集。

## 一次成图与交付

三次调用完成后直接交付三张生成结果，并明确各自对应的风格。不得对成图启动视觉复检、通过/失败判断、重试、重生成或修图流程。若工具调用本身未返回图片，只报告该调用未完成，不自动再次调用。
