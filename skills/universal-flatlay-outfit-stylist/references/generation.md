# 独立生成提示词

本文件用于三张图片的三次独立生成。把方括号字段替换为本轮实际分析结果；不要把模板中的占位符原样提交给图像工具。所有要求在首次提示词中一次写全，每套只调用一次，不追加检查、修正或重做调用。

## 每张图的提示词模板

```text
只参考本轮用户上传或明确指定的主商品图。忽略对话中此前出现的所有商品图片、品类判断、服装属性、搭配方案、配饰、背景和生成结果。本次不得从历史内容继承任何设计选择。

当前主商品：[品类]；[颜色]；[材质]；[廓形]；[长度]；[领型]；[袖型]；[图案]；[结构细节]。忠实还原这些可见特征，不改变、不简化、不重新设计主商品。

只生成一张独立的商品平铺搭配图。当前风格：[风格名称与场景倾向]。搭配单品：[逐项列出鞋履、包袋、其他服装层和少量配饰]。执行当前品类规则：[写明本方案涉及的连衣裙单穿/第三套外搭、裤装短外套，或其他品类自适应要求]。

画面为正上方 90° 俯拍，背景为均匀纯白色，只展示服装商品、鞋包和穿搭配饰。所有单品完整可见、独立平铺、互不遮挡、不得裁切、不得叠穿。间距清晰但不过大，布局紧凑、整齐、平衡，无大面积无意义空白。商品尺寸比例真实自然。

禁止人物、模特、人体模特、人体局部、手、脚、假人、衣架、家具、植物、书籍、咖啡、花朵及其他生活方式道具。禁止灰色、黑色、米色或其他非纯白背景。禁止拼图、三宫格、合集、分栏、边框、文字和标签。本次只输出当前方案的一张图。
```

三次调用都必须保留首段的本轮隔离声明，并重复完整的视觉约束。只更换当前风格及其搭配清单。

## 输入图片隔离

- 有本轮主商品的本地路径时，只向图像工具传这一路径。
- 只能通过“最近图片”机制引用附件时，使用能包含本轮主商品的最小数量，并确认其中没有历史商品图。
- 如果最小图片集合仍混入历史商品，暂停生成并请用户重新上传当前主商品。不得把历史图一并传入。
- 第二、第三张图继续引用原始主商品图；不引用先前生成的搭配图。

## 一次调用规则

- 预先为三套方案写好完整提示词，再各调用一次图像生成工具。
- 每次调用只生成当前方案的一张图片；三次调用互相独立。
- 每套方案最多一次生成调用。调用返回图片后直接作为该风格的最终结果，不进行成图复检、评分、失败判定、修正、局部编辑、重试或重生成。
- 若某次调用没有返回图片，报告工具调用未完成；不得自动再次调用。
