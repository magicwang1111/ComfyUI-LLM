# 欧美大码女装 TikTok 视频脚本｜完整要求总结

以下是本对话中你多次提出、修改和强调的要求，整合为一套长期执行规范。以后生成新商品脚本时，以这套规范为基础，结合你当次指定的剧情、拍摄方式、分镜数量及产品特点执行。

核心目标：制作适合美国TikTok带货的超写实短视频，默认15秒左右，实际时长按当次要求调整，兼顾强Hook、真实剧情、穿衣痛点、版型优势、商品细节和购买转化。

## 一、基本视频规格

| 项目 | 默认要求 |
|---|---|
| 视频时长 | 默认12–15秒，优先15秒；当次明确指定时长时按当次要求执行 |
| 画幅 | 9:16竖屏 |
| 帧率 | 60fps |
| 视频风格 | 美国本土TikTok超写实真人UGC |
| 人物 | 欧美真实大码女性 |
| 分镜数量 | 默认五分镜，特殊要求可改三分镜 |
| 叙事结构 | Hook＋F＋A＋B＋C |
| 拍摄方式 | 默认生活纪实，具体视角按当次要求 |
| 口播语言 | 自然、地道、情绪饱满的美式英语 |
| 提示词语言 | 中文 |
| 中文翻译 | 集中放在第八部分 |
| 背景音乐 | 默认禁止 |
| 字幕、Logo、水印 | 默认禁止 |

视频时长是可调整的默认要求，不固定为15秒。未指定时长时，在上述范围内根据剧情和口播选择，优先15秒；指定其他时长时，基础设定、分镜时间轴、口播量和实际生成参数必须同步调整，分镜总时长须与本次选定时长一致。

## 二、开场Hook要求（最高优先级之一）

这是你反复强调最多的部分。

第一镜必须在前1–3秒制造强烈的注意力打断，并直接指出当前商品的具体穿衣痛点或独特卖点。

### 1. 第一句必须有信息量

禁止反复使用缺少信息量的开场，例如：

- “Your dress!”
- “So cute!”
- “I love your outfit!”
- “I'm obsessed!”

要根据商品特点设计真正能吸引目标用户的内容。

例如，对于宽松上衣，可以使用：

“WAIT! How is that loose top not boxy?!”

这种开场同时包含了宽松版型、显方正的痛点和惊讶情绪。

### 2. Hook可以通过不同形式制造冲突

不要求每条视频都快速横摇镜头。

可以根据剧情选择声音、动作或故事冲突，包括突然惊呼、摄影者急停、快步追上、意外发现、人物被叫住、手部动作打断，或者在安全自然的前提下出现轻微肢体接触。

重点是突然发生的真实事件，而不是单纯为了制造冲突而夸张运镜。

### 3. 搭讪者必须足够兴奋

搭讪者的声音要高能量、明显重读、语调上扬、带有真实惊喜感。

博主可以先惊讶，再转为开心和分享状态，不需要两个人全程同时大喊。

## 三、口播内容要求

### 1. 不能只讲图案和颜色

服装带货的重点是解决用户的穿衣顾虑。

需要结合当前商品的可见版型，说明具体视觉优势，例如：

- 宽松A字版型如何自然覆盖腰腹。
- 明确的腰线如何让穿搭更有层次。
- 阔腿裤如何呈现舒展的裤腿轮廓。
- 不规则衣摆如何减少整体方正感。
- 荷叶边如何增加服装视觉层次。
- 长款上衣如何提供臀部上方的覆盖。
- 袖型如何在视觉上保留手臂活动空间。

可以强调服装对身形轮廓的修饰，但不使用羞辱身材、夸大减重或瞬间改变体型的表达。

### 2. 口播必须具有连贯性

五镜是一次完整的交流，而不是五条独立广告口号。

推荐逻辑：

具体痛点 → 版型或设计原因 → 细节展示 → 真实使用场景 → 购买引导。

每句话都应回应上一句，并引出下一步动作。

### 3. 必须和历史脚本去重

你已经明确要求不能生成几条脚本后，就开始重复相同的赞美句、痛点句或CTA。

以后每款商品都需要重新设计：

- 开场第一句。
- 痛点切入方式。
- 搭讪者和博主的对话。
- 商品细节介绍顺序。
- 结尾转化句式。

不能只更换商品名称，保留同一套口播结构和措辞。

### 4. 语速与时长

必须在本次选定的视频时长内自然说完，并为动作、对话回应和停顿留出时间。

使用简短、美式口语化句子，优先保证口型同步、表达完整和人物正常回应。

不能为了塞进过多英文词而机械加速、重叠抢话或牺牲镜头动作。

## 四、CTA与促销表达

你后来明确提高了带货强度，因此结尾不必始终像普通聊天那样含蓄。

允许自然地增强购买引导，例如：

“It's linked below. Go grab yours!”

“Check the link below!”

也可以加入折扣、优惠或促销信息，但必须有实际依据，不能虚构活动。

严格禁止：

- 任何未经确认的具体价格。
- 具体促销开始或结束时间。
- “Only today!”
- “Sale ends tomorrow!”
- 未经证实的限时、限量、库存或折扣承诺。

CTA需要由当前剧情自然引出，并尽量避免与前几条脚本重复。

## 五、分镜和镜头设计

### 1. 五分镜必须有明确分工

| 分镜 | 核心任务 | 建议景别 |
|---|---|---|
| 第一镜 H | 强Hook、穿衣痛点、人物冲突 | 中景或中远景 |
| 第二镜 F | 引出结构、版型或设计特点 | 中景 |
| 第三镜 A | 重点商品细节展示 | 近景或特写 |
| 第四镜 B | 实际使用场景和整体穿搭 | 全身景 |
| 第五镜 C | 对话闭环、购买兴趣和CTA | 中景或近景 |

这不是固定不能改变的镜头顺序。可以根据剧情灵活调整，但每个镜头都必须具有明确作用。

### 2. 必须有细节展示

你多次强调：不能五个镜头都是人物站着说话。

根据商品选择展示领口、袖口、腰部拼接、牛仔车线、针织纹理、荷叶边、裙摆、裤脚、刺绣、图案或其他真实可见细节。

细节展示必须由人物对话或实际动作自然触发。

### 3. 展示动作是选择项，不是每条都必须用

可选择博主自己轻提衣摆、展示袖口、轻触面料、整理服装，也可以让搭讪者的手进入第一人称画面触碰面料。

不允许每条脚本机械重复摸面料或拉扯面料。

陌生人触碰服装应先得到同意；伴侣之间的自然互动可以按当次剧情设计，但不能出现明显危险或令人不适的动作。

### 4. 实拍纪实感

你希望画面像真正使用手机临时拍摄，而不是商业摄影棚。

要求包括真实走路起伏、轻微不规则晃动、偶尔倾斜、短暂的画面边缘裁切、合理重新构图及真实运动模糊。

避免全程完美居中、机械稳定器式镜头、数字变焦、突然瞬移及不符合空间逻辑的拍摄角度。

## 六、拍摄视角与剧情类型

你已经使用过多种模式，因此不能将某一次特殊需求误认为所有脚本的固定规则。

**第一人称搭讪**

搭讪者持手机拍摄，通常以画外音参与；可从正面、侧前方或背后接近，具体由你当次决定。

**第三人称搭讪**

搭讪者可以入镜，与博主具有不同外貌；如果指定身材相似，则两人的大码身体比例应接近。

**一镜到底**

全程连续空间和连续拍摄，没有硬切；通过真实走动和距离变化完成细节与全身展示。

**前置自拍或对镜自拍**

博主直接对镜介绍商品，真实操作手机；需要按自拍方式调整人物动作和景别。

**开箱与单人微短剧**

可以采用开箱、试穿、悬念故事、生活体验等结构，不一定安排搭讪者。

重要规则：只有你明确要求从背后搭讪，且提供了商品背面参考时，才安排依据背面服装结构的展示。

没有背面商品图时，不擅自设计未知背面细节。

## 七、人物与商品参考图规则

商品图负责锁定服装，人物参考图负责锁定人物。两者不能混淆。

商品图锁定颜色、版型、图案、衣领、袖型、腰线、长度、裤腿、裙摆、口袋及已确认的结构细节。

人物参考图锁定脸型、五官、发型发色、肤色、年龄感、真实大码体型与身体比例。

不能从人物参考图继承原来的黑色T恤、紧身裤或其他参考穿搭。

不得擅自瘦身、缩腰、缩胯、拉长腿部或过度美颜。

视频中的同一人物、同一商品、同一配饰必须在不同镜头间保持一致。

## 八、面料与产品真实性

原则是只根据参考图可见事实作出确定性描述。

可以描述织纹、针织结构、牛仔水洗色、面料视觉垂感、可见厚度外观和真实褶皱。

但不能仅凭图片断言：

- 特别柔软、高弹、透气、抗静电。
- 防水、防污、特殊耐磨。
- 具体面料成分。
- 经过测试的塑形或功能效果。

如果你另行提供可靠的商品卖点资料，可以将相关信息加入脚本，但不能自行编造。

口袋只有在商品结构清楚、位置明确、动作合理时才安排展示。

特别需要防止服装突然变色、变长、图案漂移、口袋消失、裤腿合并、凭空出现开衩，以及物品在镜头间发生不合理变化。

## 九、场景与故事要求

场景必须符合美国本土生活语境，不能只是把人物放进漂亮背景。

此前指定过的场景包括咖啡馆、郊区住宅花园、商场、街道、小镇、农场、健身房、居家卧室及度假环境。

未来仍然需要根据具体商品重新选择合适场景。

商品的卖点应该从场景中的真实动作自然产生。

例如，整理花园时因蹲起动作引出裤腿版型；咖啡馆偶遇时因衣摆走动效果引出上衣轮廓；试穿时因视觉变化引出腰部设计。

人物不能突然从正常生活状态切换成摆拍模特。

## 十、固定脚本输出结构

你此前已经使用并认可这套完整格式，默认沿用：

1. 服装判断：品类、可见结构、痛点和卖点。
2. 基础设定：时长、比例、视角、风格及拍摄规则。
3. 人物设定与穿搭：逐人说明外貌、体型、参考约束、穿搭及人物区别。
4. 场景与剧情：环境、人物初始位置、触发事件及完整故事发展。
5. 拍摄风格与表演：摄影者身份、手持镜头特征及情绪原则。
6. 五分镜完整脚本：时间戳、英文对白、语音调教、镜头语言、人物动作表情、转场。
7. 完整英文口播：整合所有英文台词。
8. 完整中文参考：统一翻译所有口播。
9. 整体表演要求：情绪曲线与人物互动。
10. 声音规范：真实环境声和口型同步。
11. 人物、服装与场景一致性：防止生成错误。
12. Negative Prompt：针对商品和镜头的负面提示词。
13. 最终执行要求：完整概括生成目标和强制限制。

其中你明确修改过的固定规则是：

第六部分不再出现“中文参考”字段。所有台词中文翻译只放在第八部分。

如果当次要求一镜到底、三分镜或其他特殊形式，则相应调整第六部分的结构，但保留必要的拍摄和一致性说明。

### 章内展开方式

参考“猫咪毛衣／宠物用品店偶遇”范例的分组和展开密度。采用“总标题 → 十三个章节 → 章内分组 → 具体条目”的层级，不把一个章节压成包含所有要求的长段落。总标题写明当前商品、场景和剧情形式。章节使用 `## 一、服装判断` 这样的二级标题，人物和分镜使用三级标题；人物组可以写 `### 1. 博主`，不能与大章节使用同一级标题。

以下表格规定章内必须独立成行的字段或分组名称。每项填写本次商品和剧情的具体内容，不只列标签、不用“同上”“保持一致”“自然表演”等空泛句子代替展开。标签可用小标题、加粗或冒号形式。机器检查只能发现字段缺失，具体内容仍需逐项审核。

| 部分 | 必备字段（分号分隔） |
|---|---|
| 1 | 商品品类；颜色与可见设计；核心穿衣痛点；核心卖点；真实性限制 |
| 2 | 时长；画幅；帧率；画质；风格；结构；分镜；视角；人物；英文口播；音乐；字幕；本次创意重点 |
| 3 | 外貌与体型；参考约束；完整穿搭；人物区分 |
| 4 | 场景环境；人物初始位置；触发事件；完整故事发展 |
| 5 | 摄影者；镜头特征；情绪原则 |
| 6 | 时间戳；英文口播；语音调教；镜头语言；人物动作与表情；转场 |
| 9 | 情绪曲线；逐人表演；对白 |
| 10 | 允许的声音；声音空间与口型；禁止的声音 |
| 11 | 人物；服装；环境与道具 |
| 13 | 视频目标；逐镜执行；人物与表演；摄影与声音；禁止事项 |

**第一部分：服装判断。** “颜色与可见设计”下逐项写主体颜色、图案、领口、肩部、袖型、衣身、下摆和纹理，按品类替换为对应结构。痛点用完整句子解释目标用户的具体穿衣顾虑；卖点逐条对应可见结构。真实性限制保留不能虚构面料成分、功能等创作约束，不写采集过程或数据库操作。

**第二部分：基础设定。** 规格逐项独立成行；帧率写为创作目标，不在脚本里讨论检测结果。“本次创意重点”说明人物原本在做什么、什么事件打断动作、为什么会注意到这件商品，不能只写“强Hook、高能搭讪”。

**第三部分：人物设定与穿搭。** 每名参与者单独分组，分别写“外貌与体型、参考约束、完整穿搭”。有参考的人物依据实际可见信息描述，不编造未知比例；新角色的设计与参考人物清楚区分。“人物区分”说明角色差异和出镜方式。画外音人物不必编造不可见外貌；单人剧情说明单人身份连续性。不得把范例的白人博主、深棕肤色搭讪者、双人大码体型固定为所有任务的要求。

**第四部分：场景与剧情。** 分别展开场景环境、人物和摄影者的初始位置、可拍摄的触发事件。完整故事发展用事件链串起发现商品、产生问题、回应、细节、使用和购买兴趣；每一步由上一反应触发。场景和道具为当前商品服务，不照搬宠物店、猫玩具或碰撞购物篮。

**第五部分：拍摄风格与表演。** 明确摄影者是谁、是否参与对白；镜头特征逐项描述移动、重新构图、手持起伏及细节靠近方式。情绪原则区分开场高能声音和自然身体反应，不能用“不要夸张”把开场兴奋感削弱为平淡聊天。

**第六部分：逐镜展开。** 每镜以 `### 【分镜一——H：本镜具体事件】` 形式命名，依次填写表中的六个字段，最后一镜的“转场”写自然收尾。使用其他镜数时按当前要求命名；一镜到底按连续时间段展开，不添加硬切。

- 时间戳：写明起止秒数，各镜连续且总和等于本次时长。
- 英文口播：按说话者列出实际台词，画外音明确标注；无对白的镜头明确写无对白。
- 语音调教：针对本镜每位说话者的具体词句，说明重读词、音调变化、停顿和情绪动机。不能每镜只写“兴奋自然、口型同步”。
- 镜头语言：分别交代景别、起始构图、摄影者移动、商品可见范围及落点。细节镜列出要看清的结构，全身镜明确完整穿搭与空间关系。
- 人物动作与表情：按人物分别写初始动作、被触发后的反应及下一步动作。对白、动作、摄影移动在该镜时间内可完成；不要为了文字详细而给每镜堆多个复杂动作。
- 转场：解释上一动作如何引出下一镜，并保持空间和视线连续；收尾交代人物如何结束交流。

以下为一个分镜的写法示例，仅学习展开方式，不复制商品、台词和剧情：

```text
### 【分镜三——A：顺着惊喜发现领肩细节】
时间戳：00:06–00:09
英文口播：
朋友（画外音）："Shoulder buttons too?"
语音调教：
朋友重读“buttons”，尾音上扬；像刚注意到第二个设计，保持惊喜并留出回应时间。
镜头语言：
从人物斜前方靠近领肩，近景完整保留已确认的纽扣和领边。
手机带轻微手持起伏，结束时仍停在该侧肩部，不通过数字变焦制造细节。
人物动作与表情：
博主把该侧肩膀轻轻朝镜头转动，低头看一眼后微笑；手不挡住纽扣。
朋友继续在画外观察，不额外入镜。
转场：
以博主抬头回应为衔接，切到同一视线轴的全身景。
```

**第七、八部分：整合口播及翻译。** 第七部分按实际说话顺序逐人列出与分镜完全相同的英文台词，第八部分对应翻译。不要给每镜重复附中文翻译。详细的摄影和表演说明不等于增加口播量；15秒通常约30–36个英文词，按实际停顿调整，不能照搬范例的长对白再要求模型加速或自行删词。

**第九部分：整体表演。** “情绪曲线”给出连续事件和反应；“逐人表演”按实际角色分别写开场状态、反应转变及分享或购买时的表现；“对白”说明交流如何承接及卖点如何自然推进。不能重复一串笼统的禁止事项代替人物表演设计。

**第十部分：声音规范。** 允许的声音逐项列出；声音空间与口型明确说话者位置、画外音、轮流回应；禁止的声音集中说明。真实物件声只在剧情确有该动作时出现，不要求每条视频必须有碰撞音效。

**第十一部分：一致性。** 分“人物、服装、环境与道具”三组逐条填写。分别锁定身份、服装颜色和具体结构、场景布局及实际使用的道具。不用“全部保持一致”代替细节，也不增加商品不存在的设计。

**第十二部分：Negative Prompt。** 使用英文逗号分隔的明确限制，针对本次人物、商品、动作、声音和镜头编写；不套用猫咪毛衣的固定动物或图案清单，不重复堆砌相同限制。

**第十三部分：最终执行要求。** 视频目标写清规格、视角和故事；逐镜执行按镜头各写一段，提炼当前剧情事件和卖点；其余字段汇总人物表演、摄影声音和禁止事项。这里的“执行”指视频如何呈现，不是程序执行状态。

### 执行记录单独保存

`prompt.txt` 只保存可供视频创作使用的标题及完整脚本。商品PID、店铺URL和核验过程、原图编号与裁剪选择理由、数据库查询和历史去重范围、规范文件名与哈希、接口错误、提交状态、是否重试、付费授权及成片检测结果不得写入脚本。

Agent 将核验依据、裁剪选择理由、可用历史范围与去重判断、尚未确认事项和复核说明通过 `run.py prepare --execution-notes` 保存到 `execution-notes.md`。机器生成的商品记录、裁剪坐标、规范检查和任务状态继续分别保存在 `product/manifest.json`、`crop.json`、`analysis.json`、`prompt-review.json`、`status.json` 等文件。成片检测结果写入质检记录和最终回复，不回填拍摄脚本。

与画面有关的限制仍需留在脚本：例如身份和服装引用分工、不展示未知背面、不虚构面料功能。这些应表述为具体拍摄要求，不夹带“已核验、已查询、待审核、无法保证帧率”等操作说明。

## 十一、明确禁止的常见问题

不允许同一人物换脸、身材突然变化，或者在不同分镜中衣服细节不一致。

不允许人物手里拿着的裤子、咖啡杯、商品或其他道具瞬间替换。

不允许无意义地重复拉扯衣服、触摸面料、转圈、指向屏幕。

不允许虚构商品功能、材料和促销信息。

不允许前一镜与后一镜的拍摄角度、人物站位、空间距离不符合现实。

不允许因为追求高能而让所有人物持续尖叫、露出僵硬笑容或像机器人一样说广告词。

不允许背景音乐、默认字幕、可读品牌Logo、水印、购物UI和未授权的屏幕文字。

## 十二、以后执行时的优先级

为了避免你之前指出的“做几条脚本后就忘记要求”的问题，今后按照以下优先级处理：

**第一优先级：你当前消息明确提出的要求**

如“一镜到底”“从背后追上”“第三人称”“不要搭讪”“五分镜”“必须触摸面料”等。

**第二优先级：本聊天框已经确定的长期规范**

强Hook、具体痛点、版型优势、自然口播、真实大码比例、去重、细节展示及转化引导。

**第三优先级：商品图与人物参考图的真实信息**

服装结构和人物特征以对应参考图为准。

**第四优先级：根据商品特点进行原创设计**

自主选择合理的剧情、场景、人物动作、景别、细节展示方式和CTA。

最终总结：你要的不是机械套模板的服装广告，而是一条有真实故事、有强烈开场、有目标用户穿衣痛点、有清晰版型及细节展示、有自然美式高能口播、最后能促进购买的短视频。

以上规范作为后续同类脚本的默认依据；每次你提出新的特殊要求，只覆盖对应部分，不会把一次性的拍摄选择误当成所有视频的固定规则。
